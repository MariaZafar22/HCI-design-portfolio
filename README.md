## Task 1: Prototyping Environment Setup (Figma)

I registered for a free Figma account and explored the design canvas and the Figma Community, where designers share free design files. The main tools I explored:

- **Frame (F):** creates screens/artboards (e.g., mobile frame 390 x 844)
- **Rectangle (R) and Text (T):** basic shapes and text
- **Components:** reusable elements such as buttons
- **Auto Layout:** spacing and alignment that adjust automatically
- **Export panel:** export frames as PNG or PDF

## HCI Design Life Cycle

The HCI design life cycle is an iterative process used to create systems that are easy and pleasant to use.

1. **Understand users:** learn who the users are, their goals, needs and context of use.
2. **Define requirements:** decide what the system must do and what usability goals it must meet.
3. **Design and prototype:** create sketches, wireframes and interactive mockups (for example, in Figma).
4. **Evaluate:** test the prototype with users or experts using methods such as heuristic evaluation and usability testing.
5. **Iterate:** use the findings to improve the design and evaluate again until it meets user needs.

**Understand Users → Define Requirements → Design / Prototype → Evaluate → Iterate**

This week I mainly practised the *Evaluate* stage by finding usability problems in existing designs and suggesting fixes that will feed into the *Iterate* stage.
